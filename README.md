# OneMore

Habitly is a simple and elegant habit tracking app built with **SwiftUI**. It helps users develop positive habits by tracking daily progress, maintaining streaks, and visualizing consistency through an intuitive and minimalist interface.

## ✨ Features

- 📅 Track daily habits
- ✅ One-tap habit completion
- 🔥 Daily and longest streak tracking
- 📊 Progress statistics
- 🗓️ Calendar history
- ⏰ Local reminders
- 🌙 Dark Mode support
- 🎨 Clean and modern UI
- 💾 Local data persistence with SwiftData

## 🏗️ Architecture

This project follows **Clean Architecture** with the **MVVM** design pattern.

```
Presentation
├── Views
├── ViewModels

Domain
├── Entities
├── UseCases
├── Repositories

Data
├── Models
├── Repository Implementations
├── Local Storage
```
